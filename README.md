# Basic Banking System - Spring Boot Terminal Application

The final project is a simple Banking Application. The purpose of this project is to
demonstrate how a simple banking system works, especially in managing bank accounts,
checking balances, and doing different banking transactions. The application must implement
the required features below.


## Features

- Register a user
- Automatically create a bank account
- Login
- Check balance
- Deposit money
- Withdraw money
- View transaction history
- Logout
